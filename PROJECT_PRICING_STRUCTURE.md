# ConstructKaro ERP - Pricing Structure

## Project Overview

ConstructKaro ERP is a construction business management system with admin panel, mobile API backend, attendance, labour, project, purchase, inventory, vehicle, safety, report, PDF, and company management modules.

## Main Modules Included

- Admin dashboard
- Multi-company management
- Company subscription management
- Employee management
- Employee attendance
- Leave requests
- Missed attendance requests
- Labour attendance
- Labour master, contractor master, and site master
- Labour costing
- Vehicle management
- Driver attendance
- Vehicle maintenance
- Diesel purchase and machinery diesel logs
- Daily Progress Reports with photos
- Challan management with PDF
- Payment records and payment slips
- Material master
- Stock list and stock adjustment
- Material requests and material issues
- Safety store
- Supplier master
- Unit master
- Product purchases
- Purchase workflows
- Purchase orders with PDF
- Project management
- BOQ management
- Site reports
- FDD test records
- MIR file reports
- Complaint management
- API support for mobile app
- WhatsApp message integration

## Option 1: Monthly Subscription Model

In this model, the client pays a one-time setup fee and then pays monthly for using the system.

| Plan | Best For | Setup Fee | Monthly Fee |
|---|---|---:|---:|
| Basic | Small contractor or single site | Rs. 25,000 | Rs. 4,999/month |
| Standard | Medium construction company | Rs. 50,000 | Rs. 9,999/month |
| Professional | Multiple sites and more users | Rs. 75,000 | Rs. 14,999/month |
| Enterprise | Large company with custom needs | Rs. 1,00,000+ | Rs. 24,999/month+ |

## Monthly Plan Details

### Basic Plan - Rs. 4,999/month

- 1 company
- 1 to 2 sites
- Employee attendance
- Labour attendance
- Basic reports

- Basic support

### Standard Plan - Rs. 9,999/month

- 1 company
- Up to 5 sites

- DPR reports
- Challans

- Vehicle management
- Material stock
- Purchase records
- PDF reports
- WhatsApp integration support
- Monthly support

### Professional Plan - Rs. 14,999/month

- Multiple sites
- All Standard Plan features
- Project management
- BOQ management
- Purchase orders
- Safety store
- Labour costing
- Vehicle maintenance
- Advanced reports
- Priority support

### Enterprise Plan - Rs. 24,999/month+

- All modules included
- Custom reports
- Custom changes
- Dedicated server setup
- Staff training
- Priority support
- Data backup support
- Custom branding

## Recommended Monthly Offer

For most clients, the best offer is:

**Rs. 50,000 setup fee + Rs. 9,999/month**

This is suitable for a medium construction company and gives you monthly recurring income.

## Option 2: One-Time Sale Model

In this model, the client pays one fixed amount for setup and usage.

| Package | What Is Included | Price |
|---|---|---:|
| Basic One-Time | Setup, branding, basic training | Rs. 75,000 to Rs. 1,25,000 |
| Standard One-Time | Setup, branding, training, 1 month support | Rs. 1,50,000 to Rs. 2,50,000 |
| Premium One-Time | Full setup, custom changes, reports, 3 months support | Rs. 3,00,000 to Rs. 5,00,000 |
| Full Source Code Sale | Complete source code handover | Rs. 5,00,000 to Rs. 10,00,000+ |

## Recommended One-Time Offer

For a serious client, quote:

**Rs. 3,50,000 one-time**

Negotiation range:

- Best price: Rs. 3,50,000
- Acceptable price: Rs. 2,50,000
- Minimum price: Rs. 1,50,000

Do not sell the full source code below Rs. 5,00,000 if the buyer wants complete ownership.

## Customization Charges

Extra changes should be charged separately.

| Work Type | Suggested Charge |
|---|---:|
| Small text/design changes | Rs. 2,000 to Rs. 5,000 |
| New report | Rs. 5,000 to Rs. 15,000 |
| New module | Rs. 25,000 to Rs. 75,000 |
| Mobile app changes | Rs. 10,000 to Rs. 50,000 |
| WhatsApp/SMS integration | Rs. 10,000 to Rs. 25,000 |
| Server deployment | Rs. 10,000 to Rs. 25,000 |
| Data import from Excel | Rs. 5,000 to Rs. 20,000 |

## Support Charges

| Support Type | Price |
|---|---:|
| Basic monthly support | Rs. 5,000/month |
| Standard monthly support | Rs. 10,000/month |
| Priority support | Rs. 20,000/month |
| On-site training | Rs. 10,000 to Rs. 25,000/day |

## Payment Terms

### For Monthly Subscription

- 50% setup fee advance
- 50% setup fee after deployment
- Monthly payment in advance
- Support starts after final setup payment

### For One-Time Sale

- 50% advance before work starts
- 30% after demo/deployment
- 20% after final handover

### For Source Code Sale

- 70% advance
- 30% before source code handover
- Source code should be shared only after full payment

## Important Conditions

- Hosting/server cost is extra unless included in the plan.
- Domain cost is extra.
- SMS/WhatsApp API charges are extra.
- Payment gateway charges are extra.
- Custom changes are not included unless written in the agreement.
- Source code ownership is not included in monthly subscription.
- Client data belongs to the client.
- Software ownership remains with the developer unless full source code sale is agreed.
